

## Требования

- Node.js 18+ (рекомендуется актуальная LTS-версия).
- npm.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который Vite выведет в терминале (обычно `http://localhost:5173`).

## Проверка production-сборки

```bash
npm run build
npm run preview
```


## Оценка времени

Ориентировочное время выполнения: **45–60 минут**.
